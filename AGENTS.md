# Fluxo de trabalho da Clara

- Use as [issues da Clara](https://github.com/hayax0/clara-clinicas/issues) como fila de execução. Quando receber um número de issue, leia a descrição, as dependências diretas e os arquivos relevantes ao aceite.
- Mantenha uma entrega verificável por issue. Registre objetivo, escopo, critérios de aceite e referências curtas. Abra issues separadas para descobertas fora do escopo.
- Consulte `docs/IMPLEMENTATION_STATUS.md` para saber o que está validado e `docs/ROADMAP.md` para priorização. Abra o prompt mestre quando a issue depender de um requisito que as referências curtas não resolvam.
- Ao concluir, registre na issue as mudanças, os testes executados e as limitações relevantes. Quando houver PR autorizado, vincule a issue ao PR.
- Leia `docs/PASSAGEM_DE_CONTEXTO.md` ao retomar. Atualize-o antes de passar para a próxima fase e ao concluir cada entrega, com decisões alteradas, issue, evidência de teste, pendências e próximo passo.
